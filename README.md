# Autism Spectrum Disorder (ASD) Prediction Using Machine Learning

## Overview

This project develops and compares machine-learning models for predicting Autism Spectrum Disorder (ASD) status using demographic, developmental, and family-history characteristics.

The study compares seven classification approaches:

- Logistic Regression
- LASSO / Elastic-Net Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbours (KNN)
- Gradient Boosting Machine (GBM)
- XGBoost

The primary objective is to evaluate and compare the ability of these models to discriminate between ASD-positive and ASD-negative individuals.

The focus here is on prediction rather than causal inference. 

The data has been obtained from Kaggle.
